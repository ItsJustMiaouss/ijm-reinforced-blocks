## 🔨 IJM's Reinforced Blocks

#### Add indestructible and ownable blocks!

This mod adds reinforced blocks like the [SecurityCraft](https://github.com/Geforce132/SecurityCraft) ones. These blocks can only be broken by the player who own them.

### 📌Features

You first need to craft the **Reinforcer** item. By right-clicking on blocks, you'll be able to reinforced them.

![Reinforcer Craft](https://cdn.modrinth.com/data/cached_images/61e0a5441dab574c4279b89374ada681a7550e23.png)

The reinforced blocks cannot be broken by the wither, the ender dragon, some explosions or moved by pistons. They also occult sounds like wool blocks.
